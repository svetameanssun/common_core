# Libft

This is the first project as a student at [42](https://42.fr/en/homepage/). The objective is to recreate essential functions from the **C standard library** (`libc`), as well as additional utility functions that will serve as a foundation throughout the curriculum.

---

## 💡 Key Concepts
This project goes beyond re-implementing standard library functions — it provides a deep understanding of how low-level operations work. It also serves as an introduction to working in a **Unix environment**, using **Git** for version control, managing builds with **Makefiles**, and conducting thorough testing.

---

## 🧠 Programming Concepts
* Memory Manipulation
* String Handling
* Type Casting
* Character Operations
* Data Structures (Linked Lists)

---

## 🛠️ Technologies
* **Language:** C
* **Build System:** Makefile
* **Version Control:** Git
* **Standards:** C Standard Library (`libc`)

---

## 🎯 Hard Skills

## 🤝 Soft Skills
* **Attention to Detail & Rigor:** Strictly following specification guidelines and maintaining zero memory leaks.
